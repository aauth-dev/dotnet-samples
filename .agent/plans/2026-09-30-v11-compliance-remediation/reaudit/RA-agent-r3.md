## Verified compliant

- HTTP-signature producer honors the owner Q1 ruling: it waits for the next free second, uses the actual current `TimeProvider` value as `created`, observes cancellation while waiting, and never future-dates (`src/AAuth/HttpSig/AAuthSigningHandler.cs:68`, `:105`, `:110`, `:290`; `AAuthSigningHandlerTests::SendAsync_CancelledWhileWaiting_SendsNothing`, `tests/AAuth.Tests/HttpSig/AAuthSigningHandlerTests.cs:112`).
- Body-bearing signing now covers both `content-type` and `content-digest` and fails closed when `Content-Type` is absent (`src/AAuth/HttpSig/AAuthSigningHandler.cs:197`, `:203`, `:435`; `AAuthSigningHandlerTests::SendAsync_BodyWithoutContentType_ThrowsBeforeSending`, `tests/AAuth.Tests/HttpSig/AAuthSigningHandlerTests.cs:494`).
- Automatic AP two-key refresh was removed rather than half-wired; manual two-key refresh still exposes the matching key/token pair (`src/AAuth/Agent/AgentProviderTokenRefresher.cs:52`, `src/AAuth/Agent/AgentProviderClient.cs:185`; `AgentProviderTokenRefresherTests::AutomaticTwoKeyRefreshSurface_IsRemoved`, `tests/AAuth.Tests/Agent/AgentProviderTokenRefresherTests.cs:78`).
- Agent, person, and auth carrier reuse now respects the five-minute refresh margin in the covered SDK paths (`src/AAuth/Agent/TokenRefreshHandler.cs:28`, `src/AAuth/Agent/AAuthTokenCache.cs:114`, `src/AAuth/Agent/AAuthTokenHolder.cs:107`, `src/AAuth/Agent/ChallengeHandler.cs:403`).
- Auth-token response verification requirements are outside the original findings but the reviewed R3/agent paths continue checking resource/audience/key/account/lifetime in existing token verifiers; no regression was found in the cited area (`#auth-token-response-verification`, L1816-L1825).
- R3 authorization endpoint extension carries typed `r3_operations`, duplicate bare IDs are rejected, resource-token minting requires reference validation, and AS issuance validates fetched documents/proposals before minting (`src/AAuth.R3/R3AuthorizationEndpointExtensions.cs:19`, `src/AAuth.R3/R3OperationValidation.cs:78`, `src/AAuth.R3/R3Challenge.cs:69`, `src/AAuth.R3/R3AccessTokenEndpoint.cs:485`).
- R3 document fetch opacity is now entitlement-based for both AS and PS; configured-but-not-entitled signers fail (`src/AAuth.R3/R3DocumentEndpoint.cs:50`, `src/AAuth.R3/R3Challenge.cs:130`).
- Per-call retry enforcement no longer returns plain `Granted`; callers must execute through `SingleUseGrant.ExecuteOnceAsync` and receive retained results on replay (`src/AAuth.R3/R3Enforcement.cs:200`, `:209`, `:281`).
