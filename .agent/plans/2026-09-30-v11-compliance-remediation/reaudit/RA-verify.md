## Verified compliant

- Unsupported `Signature-Key` schemes are rejected at the verification step with `401 Signature-Error: error=unsupported_scheme` plus `Accept-Signature-Scheme`, satisfying `#verification` L2247 and `#scheme-rejection` L2256-L2267 — `src/AAuth/Server/Verification/AAuthVerificationMiddleware.cs:111`, `src/AAuth/Server/Verification/AAuthVerificationMiddleware.cs:410`.
- Auth/person token `aud` checks are bound to the resource's own identifier and fail closed without one, satisfying `#auth-tokens` L1809-L1815 and `#common-verification` L2322-L2323 — `src/AAuth/Server/Verification/AAuthVerificationMiddleware.cs:400`, `src/AAuth/DependencyInjection/AAuthResourceServiceCollectionExtensions.cs:68`.
- Four-party resources derive AS-only auth-token issuer trust and AS `dwk` pinning from `AccessServer`, satisfying the federated access / AS policy model in `#resource-access-modes` L386-L430 and `#policy-evaluation-points` L452-L453 — `src/AAuth/Server/Verification/AAuthResourceVerificationDefaults.cs:34`, `src/AAuth/Server/Verification/AAuthResourceVerificationDefaults.cs:69`.
- The authorization endpoint requires a verified person token and returns `400 invalid_request` for non-JSON or malformed JSON request bodies, satisfying `#authorization-endpoint-request` L667-L724 — `src/AAuth/DependencyInjection/AAuthApplicationBuilderExtensions.cs:153`, `src/AAuth/DependencyInjection/AAuthApplicationBuilderExtensions.cs:162`.
- `AgentTokenRequired` no longer admits person/auth tokens; only agent tokens pass through, matching agent-identity access in `#resource-access-modes` L278-L280 — `src/AAuth/Server/Challenge/AAuthChallengeMiddleware.cs:90`.
- Built-in and companion JWT paths reject unsupported critical JOSE headers, satisfying common verification via RFC 7515 (`#common-verification`, L2311-L2313) — `src/AAuth/Tokens/TokenVerifier.cs:753`, `src/AAuth/HttpSig/NamingTokenVerifier.cs:19`.
- Auth-token response validation now checks returned-token `typ`, `dwk`, issuer/audience/person/key/scope/lifetime, and issuer signature by default, satisfying `#auth-token-response-verification` L1817-L1825 — `src/AAuth/Agent/TokenExchangeClient.cs:187`, `src/AAuth/Tokens/AgentAuthTokenValidator.cs:27`.
