## Verified compliant

- Deferred auth-token delivery now reuses the generic poll core, signs
  bodyless `GET`s, honors `Retry-After`, treats `429 slow_down` as retryable,
  and can re-exchange a fresh auth-token requirement while staying on the same
  pending `Location` (`src/AAuth/Agent/ChallengeHandler.cs:196`-`:329`;
  `tests/AAuth.Tests/Agent/ChallengeHandlerTests.cs:420`-`:534`).
- Polling error and token error helper tables are closed for the registered
  enums (`src/AAuth/Server/AAuthProblemDetails.cs:10`-`:52`;
  `tests/AAuth.Tests/Server/AAuthProblemDetailsTests.cs:16`-`:54`).
- Governance metadata no longer advertises the browser consent path as
  `interaction_endpoint`; governance paths are derived together and omitted
  when governance is off (`src/AAuth/Person/AAuthPersonServerEndpoints.cs:241`-`:244`;
  `src/AAuth/DependencyInjection/AAuthPersonServerServiceCollectionExtensions.cs:190`-`:199`;
  `tests/AAuth.Tests/Server/ServerRoleRegistrationTests.cs:245`-`:269`).
- Governance request authorization now binds the agent token `ps` to the
  mapped PS before mission, permission, audit, or interaction work
  (`src/AAuth/Server/Governance/GovernanceEndpoints.cs:75`-`:86`;
  `tests/AAuth.Conformance/Missions/GovernanceEndpointMapperTests.cs:102`-`:115`).
- Default governance relay is fail-closed/unavailable; malformed relay state
  fails rather than returning a success-shaped `200` (`src/AAuth/Server/Governance/DefaultInteractionRelay.cs:21`-`:26`;
  `tests/AAuth.Conformance/Missions/GovernanceDeferredConsentMapperTests.cs:549`-`:615`).
- Mission status evaluation is centralized for governance paths and pending
  governance polls, including `expires_at` auto-termination with
  `termination_reason=expired` (`src/AAuth/Server/Governance/MissionStatusEvaluator.cs:20`-`:64`;
  `src/AAuth/DependencyInjection/AAuthGovernanceApplicationBuilderExtensions.cs:373`-`:384`).
