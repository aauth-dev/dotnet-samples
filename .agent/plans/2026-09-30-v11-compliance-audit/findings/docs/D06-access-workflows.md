## Verified compliant

- Identity-based access correctly describes agent-token `jwt` signing with no PS/token exchange and resource-local access control — `docs/workflows/identity-based-access.md:7-24`, `:32-39`; spec `#overview-identity-access` L278-L293.
- Resource-managed client guidance correctly separates the `aa-agent+jwt` Signature-Key credential from the opaque `AAuth-Access` token and replays the latter as `Authorization: AAuth <token68>` covered by the HTTP signature — `docs/workflows/resource-managed-access.md:13-16`, `:48-74`; spec `#aauth-access` L595-L613.
- Resource-managed server helper guidance uses `ResolveAAuthAccessAsync`, `RequireAAuthInteraction`, and `MapAAuthInteractionPoll` behind signature verification, matching the current SDK APIs — `docs/workflows/resource-managed-access.md:106-129`; SDK `src/AAuth/Server/ResourceManaged/AAuthResourceManagedHttpContextExtensions.cs`, `src/AAuth/Server/ResourceManaged/AAuthInteractionEndpointExtensions.cs`.
- PS-asserted flow uses draft-11 `presented_token` terminology for the PS token endpoint and notes resource-token pair verification of `jti`, `sub`, `mission_s256`, and `tenant` — `docs/workflows/ps-asserted-access.md:155-169`; spec `#ps-token-endpoint` L936-L945 and resource-token verification L763-L767.
- Federated flow correctly says the PS-to-AS request carries `resource_token`, `agent_token`, and `presented_token`, and that AS-issued auth tokens use `dwk: aauth-access.json` — `docs/workflows/federated-access.md:19-21`, `:157-166`; spec `#ps-to-as-token-request` L1579-L1588 and `#ps-as-collapse` L1761-L1762.
- Claims push prose correctly says the AS MUST NOT request `sub` and the PS MUST NOT include it; the SDK callback rejects protocol-owned names when serializing `ClaimsResponse` — `docs/workflows/federated-access.md:251-295`; spec `#requirement-claims` L1680.
- Spot-checked intra-repo links resolved for Dependency Injection, Inbox consent endpoints, MockPersonServer consent dashboard, token issuance `#one-call-person-server-mapaauthpersonserver`, and Mock Access Server README.
