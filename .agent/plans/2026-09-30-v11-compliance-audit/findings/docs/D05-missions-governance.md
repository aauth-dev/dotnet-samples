- Mission approval/blob documentation uses `s256`, base64url `mission`, `capabilities`, `person_tokens`, `agent`, `approved_at`, `expires_at`, `approved_tools`, and `approved_resources` consistently with draft-11 — `docs/advanced/missions.md:25-88`; spec `#mission-approval` L1360-L1427; SDK `src/AAuth/Agent/Mission.cs`.
- Mission update/completion requests use `POST {mission_endpoint}/{mission_s256}` with `action: update` / `action: completion` and no interaction-endpoint completion type on the agent client — `docs/advanced/mission-governance-clients.md:142-165`; spec `#missions` L1315-L1321, `#mission-update` L1457-L1479, `#mission-completion` L1485-L1507; SDK `src/AAuth/Agent/Governance/MissionClient.cs`.
