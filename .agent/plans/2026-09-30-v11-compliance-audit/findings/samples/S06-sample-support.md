## Verified compliant

- Sample loopback HTTP relaxation is explicitly scoped to fixed localhost origins and attached as an `EnforcesEgressPolicy` transport contract, not an SDK-global or non-loopback bypass — `samples/SampleEgress.cs:8`, `samples/SampleEgress.cs:14`, `samples/SampleEgress.cs:23`; README documents the development-only scope at `samples/README.md:42`–`samples/README.md:56`.
- Event AP store durably records an event before returning `202`, computes the inbox receipt from `(iss,jti)`, and agent receipt storage uses `INSERT OR IGNORE` keyed by `(issuer,jti)` — `samples/EventSupport/SqliteEventStore.cs:86`, `samples/EventSupport/SqliteEventStore.cs:92`, `samples/EventSupport/SqliteEventStore.cs:95`, `samples/EventSupport/SqliteEventStore.cs:269`.
- Protected event subscription tickets are single-use, short-lived, and bound to the subscribe token key thumbprint plus operation/account/resource state — `samples/EventSupport/SqliteEventStore.cs:181`, `samples/EventSupport/SqliteEventStore.cs:185`, `samples/EventSupport/SqliteEventStore.cs:190`; AsyncAPI describes the ticket URL as single-use — `samples/EventSupport/BookingsEvents.cs:124`–`samples/EventSupport/BookingsEvents.cs:125`.
- Event delivery examples resolve the AP `event_endpoint` from AP metadata at delivery time and send event tokens with the `self-jwt` scheme — `samples/EventSupport/EventDemoCode.cs:91`–`samples/EventSupport/EventDemoCode.cs:93`; `samples/EventSupport/BookingsEvents.cs:74`–`samples/EventSupport/BookingsEvents.cs:75`.

- Federated worker scenario models a one-level sub-agent (`aauth:aria+worker1@...`) with `parent_agent`, has the parent sign PS exchanges carrying `subagent_token`, validates the issued grant, and proves the parent cannot present the worker-bound auth token — `samples/FederatedWorkerScenario.cs:21`–`samples/FederatedWorkerScenario.cs:22`, `samples/FederatedWorkerScenario.cs:34`, `samples/FederatedWorkerScenario.cs:77`–`samples/FederatedWorkerScenario.cs:79`, `samples/FederatedWorkerScenario.cs:98`–`samples/FederatedWorkerScenario.cs:101`, `samples/FederatedWorkerScenario.cs:112`–`samples/FederatedWorkerScenario.cs:118`, `samples/FederatedWorkerScenario.cs:131`.
