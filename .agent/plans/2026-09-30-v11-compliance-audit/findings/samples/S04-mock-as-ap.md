## Verified compliant

- Federated AS default trust is an allow-list (`http://localhost:5100`), not open brokering — `samples/MockAccessServers/Federated/Program.cs:48-50`, `:83`.
- R3 AS default trust is also an allow-list and documents/implements empty-list deny-all semantics — `samples/MockAccessServers/R3/Program.cs:17-19`, `:51`; `samples/MockAccessServers/README.md:34-36`.
- Federated and R3 AS metadata are delegated to SDK helpers that publish `issuer`, `jwks_uri`, `auth_token_endpoint`, and `revocation_endpoint` — `src/AAuth/Access/AAuthAccessServerEndpoints.cs:142-148`; `src/AAuth.R3/R3AccessTokenEndpoint.cs:48-55`.
- R3 AS sets policy-owned `r3_per_call` splitting rather than trusting the resource to decide — `samples/MockAccessServers/R3/Program.cs:26-29`, `:52-55`.
- R3 AS uses a persistent SQLite audit sink, rejects `:memory:`, and writes issuance/audit rows in one transaction — `samples/MockAccessServers/R3/SqliteR3AuditSink.cs:11-18`, `:33-51`.
- AP metadata includes `event_endpoint` while events are mapped, and advertises `localhost_callback_allowed` explicitly — `samples/MockAgentProvider/Program.cs:14`, `:29`, `:41-50`; spec `#agent-provider-metadata` L2028-L2029.
- AP-issued/refresh agent tokens use the SDK builder default one-hour lifetime, satisfying the ≤24h SHOULD — `src/AAuth/Tokens/AgentTokenBuilder.cs:66-67`; refresh response `expires_in = 3600` at `samples/MockAgentProvider/Program.cs:203-204`.
- AP includes `ps` in agent tokens whenever the enrollment record has a Person Server — `samples/MockAgentProvider/Program.cs:226-238`; `src/AAuth/Tokens/AgentTokenBuilder.cs:182-184`; spec `#agent-governance` L459 and `#agent-token-structure` L521-L523.
- AP two-key refresh proves the durable key via the naming JWT, verifies the HTTP signature with the ephemeral key, and returns a new token bound to that ephemeral key — `samples/MockAgentProvider/Program.cs:151-153`, `:160-174`, `:190-193`.
- Sub-agent identifier format is enforced by the SDK token builder the AP uses; this sample does not expose a sub-agent issuance endpoint — `src/AAuth/Tokens/AgentTokenBuilder.cs:120-156`; `samples/MockAgentProvider/Program.cs:226-238`.
