## Verified compliant

- Federated AS trust is explicitly pinned, avoiding the SDK open-trust default for this host — `samples/MockPersonServer/Program.cs:73-75`, `:115`; README documents the pinning at `samples/MockPersonServer/README.md:96-100`.
- PS metadata paths are configured for the SDK mapper, including `mission_endpoint`, `permission_endpoint`, `audit_endpoint`, and the PS relay `interaction_endpoint` at `/mission-interaction` — `samples/MockPersonServer/Program.cs:108-112`; the mapper publishes required PS fields and `revocation_endpoint` — `src/AAuth/Person/AAuthPersonServerEndpoints.cs:188-200` (`#ps-metadata`, L2058–L2068).
- Browser consent distinguishes resource-asserted and agent-asserted content, attributes agent assertions, and HTML-encodes rendered values — `samples/MockPersonServer/Program.cs:935-947` (`#consent-presentation`, L1031–L1041).
- Mission approval returns the blob, `s256`, and optional mission person tokens after persisting the same mission — `samples/MockPersonServer/Program.cs:299-306`, `:351-356` (`#mission-approval`, L1412–L1417; `#mission-identifier`, L1437).
- Mission update requires `action: update`, requires `description`, appends the persisted update bytes, and returns their `s256` — `samples/MockPersonServer/Program.cs:530-544` (`#mission-update`, L1468–L1472).
- Governance authorization rejects non-agent carriers and checks mission ownership/state/expiry through `GovernanceEndpoints.Authorize` on permission, audit, interaction, mission-action, and permission-pending paths — `src/AAuth/Server/Governance/GovernanceEndpoints.cs:31-45`; call sites include `samples/MockPersonServer/Program.cs:396`, `:472`, `:503`, `:535`, `:585` (`#person-server`, L786; `#mission-approval`, L1425; `#mission-status-errors`, L1550–L1567).
- Permission responses use `permission: granted|denied` and mission-scoped requests are logged — `samples/MockPersonServer/Program.cs:430-446` (`#permission-endpoint`, L1223–L1241).
- Audit requires a parsed mission/action record, authorizes the mission, records through the sink, and returns `201 Created` — `samples/MockPersonServer/Program.cs:461-475` (`#audit-endpoint`, L1243–L1287).
