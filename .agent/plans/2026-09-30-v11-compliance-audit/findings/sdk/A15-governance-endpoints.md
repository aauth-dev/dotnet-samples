## Verified compliant

- Agent-side permission producer uses the spec field names `action`, `description`, `parameters`, and `mission_s256` — `src/AAuth/Agent/Governance/PermissionRequest.cs:32`, `src/AAuth/Agent/Governance/PermissionRequest.cs:43`.
- Agent-side audit producer requires `mission_s256`/`action` and emits `description`, `parameters`, and `result` with spec names — `src/AAuth/Agent/Governance/AuditRecord.cs:93`, `src/AAuth/Agent/Governance/AuditRecord.cs:98`, `src/AAuth/Agent/Governance/AuditRecord.cs:107`, `src/AAuth/Agent/Governance/AuditRecord.cs:111`.
- Agent-side interaction producer emits `type`, `description`, `url`, `code`, `question`, `max_wait`, and `mission_s256` with spec names — `src/AAuth/Agent/Governance/InteractionRequest.cs:69`, `src/AAuth/Agent/Governance/InteractionRequest.cs:75`, `src/AAuth/Agent/Governance/InteractionRequest.cs:76`.
- Mission completion is not sent to the interaction endpoint by the client or accepted by the server parser — `src/AAuth/Agent/Governance/InteractionClient.cs:45`, `src/AAuth/Server/Governance/GovernanceEndpoints.cs:101`, `src/AAuth/Server/Governance/GovernanceEndpoints.cs:106`.
- Mission-bound governance calls reject missing/foreign missions with 404 and terminated/expired missions with 403 `mission_terminated` — `src/AAuth/Server/Governance/GovernanceEndpoints.cs:39`, `src/AAuth/Server/Governance/GovernanceEndpoints.cs:43`, `src/AAuth/Server/Governance/GovernanceEndpoints.cs:44`; covered by `tests/AAuth.Conformance/Missions/GovernanceEndpointMapperTests.cs:164` and `tests/AAuth.Conformance/Missions/GovernanceEndpointMapperTests.cs:203`.
- Audit without `mission_s256` is rejected by the parser; valid audit acknowledgements return 201 — `src/AAuth/Server/Governance/GovernanceEndpoints.cs:79`, `src/AAuth/DependencyInjection/AAuthGovernanceApplicationBuilderExtensions.cs:255`, `src/AAuth/DependencyInjection/AAuthGovernanceApplicationBuilderExtensions.cs:256`.
- Permission default policy is not fail-open for unknown actions: it prompts rather than grants — `src/AAuth/Server/Governance/DefaultPermissionDecider.cs:23`, `src/AAuth/Server/Governance/DefaultPermissionDecider.cs:36`; test `tests/AAuth.Tests/DependencyInjection/AAuthGovernanceDITests.cs:44`.
