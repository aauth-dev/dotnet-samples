## Verified compliant

- Agent-side generic deferred polling uses signed bodyless `GET`, can send `Prefer: wait=N`, enforces a max total wait, and supports cancellation — `src/AAuth/Agent/DeferredPoller.cs:150`, `src/AAuth/Agent/DeferredPoller.cs:158`, `src/AAuth/Agent/DeferredPoller.cs:160`, `src/AAuth/Agent/DeferredPoller.cs:171`.
- Generic deferred polling honors relative/absolute `Retry-After` values and implements cumulative `429` linear backoff outside the auth-token challenge path — `src/AAuth/Agent/DeferredPoller.cs:195`, `src/AAuth/Agent/DeferredPoller.cs:197`, `src/AAuth/Agent/DeferredPoller.cs:259`, `src/AAuth/Agent/DeferredPoller.cs:267`.

- Pending URL same-origin validation rejects cross-origin, fragment, backslash, control, and non-ASCII `Location` values before polling/pushing — `src/AAuth/Discovery/AAuthEgressPolicy.cs:124`, `src/AAuth/Discovery/AAuthEgressPolicy.cs:131`; used by `src/AAuth/Agent/DeferredExchange.cs:383`, `src/AAuth/Access/AccessServerClient.cs:447`, and `src/AAuth/Agent/ChallengeHandler.cs:218`.
