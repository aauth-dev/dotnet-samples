## Verified compliant

- Signed auth-token calls require an agent token carrier; non-agent carriers are rejected before body processing — `src/AAuth/Person/AAuthPersonServerEndpoints.cs:324`, `src/AAuth/Person/AAuthPersonServerEndpoints.cs:328`.
- `resource_token` and `presented_token` are required request parameters — `src/AAuth/Person/AAuthPersonServerEndpoints.cs:574`, `src/AAuth/Person/AAuthPersonServerEndpoints.cs:577`.
- Sub-agent requests require a sub-agent token naming the signing parent and sharing its issuer; the bound key becomes the sub-agent key — `src/AAuth/Tokens/AgentIssuanceContext.cs:88`, `src/AAuth/Tokens/AgentIssuanceContext.cs:100`.
- Resource token verification checks signature/type/audience, `agent_jkt`, and `ps == this PS`; presented-token verification checks type, audience substitution, `cnf`, `jti`, PS, subject, mission, and tenant — `src/AAuth/Person/AAuthPersonServerEndpoints.cs:369`, `src/AAuth/Tokens/TokenVerifier.cs:571`, `src/AAuth/Tokens/TokenVerifier.cs:580`, `src/AAuth/Tokens/TokenVerifier.cs:588`, `src/AAuth/Tokens/TokenVerifier.cs:345`, `src/AAuth/Tokens/TokenVerifier.cs:357`.
- Mission-bearing resource tokens are checked for active mission ownership and expiry — `src/AAuth/Person/AAuthPersonServerEndpoints.cs:1018`, `src/AAuth/Person/AAuthPersonServerEndpoints.cs:814`.
- Fresh auth-token responses are bounded by agent/upstream/presented/mission expiry on the non-replacement path — `src/AAuth/Person/AAuthPersonServerEndpoints.cs:1017`, `src/AAuth/Person/AAuthPersonServerEndpoints.cs:1215`, `src/AAuth/Server/AuthTokenResponse.cs:60`, `src/AAuth/Server/AuthTokenResponse.cs:94`.
- Pending requests use unguessable IDs and limited lifetime — `src/AAuth/Person/IPersonPendingStore.cs:303`, `src/AAuth/Person/IPersonPendingStore.cs:159`.
- Pending polls are bound to the original agent token issuer, subject, and key thumbprint — `src/AAuth/Person/AAuthPersonServerEndpoints.cs:614`, `src/AAuth/Person/AAuthPersonServerEndpoints.cs:1584`.
- Terminal pending results become `410 Gone` on later poll, and cancellation/withdrawal also returns gone — `src/AAuth/Server/DeferredState.cs:29`, `src/AAuth/Server/DeferredState.cs:62`, `src/AAuth/Person/AAuthPersonServerEndpoints.cs:795`.
